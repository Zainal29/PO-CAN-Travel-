# 2. Ringkasan Produk

PO CAN Travel adalah aplikasi web untuk mengelola pemesanan tiket bus secara online.

Sistem memiliki dua role:

* `admin`
* `customer`

Customer dapat mencari perjalanan, melihat detail perjalanan, memilih kursi, mengisi data penumpang, membuat order, melakukan pembayaran, mengunggah bukti pembayaran, melihat status order, melihat riwayat pesanan, dan membatalkan pesanan sesuai aturan.

Admin dapat mengelola bus, perjalanan, customer, order, dan pembayaran serta melakukan verifikasi pembayaran.

# 3. Tujuan Produk

Menyediakan sistem pemesanan tiket bus yang lebih terstruktur sehingga proses:


# 11. Booking Transaction

Booking wajib menggunakan database transaction.

Flow:

```text
BEGIN TRANSACTION
        ↓
LOCK ROUTE
        ↓
CHECK AVAILABLE SEATS
        ↓
CHECK SELECTED SEATS
        ↓
CREATE ORDER
        ↓
CREATE ORDER DETAILS
        ↓
CREATE PAYMENT
        ↓
UPDATE AVAILABLE SEATS
        ↓
COMMIT
```

Jika terjadi error:

```text
ROLLBACK
```

Tujuannya mencegah:

* double booking;
* kursi berkurang tetapi order gagal;
* order berhasil tetapi detail tidak tersimpan;
* payment tidak sesuai dengan order.
