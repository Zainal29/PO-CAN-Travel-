### MASALAH 1 (KRITIS): Bug Pilih Kursi - Tidak Bisa Ganti Kursi
**File:** `resources/views/customer/bookings/create.blade.php`

**Deskripsi Bug:**
User tidak bisa memilih kursi dari grid jika semua penumpang sudah punya kursi. 
Contoh skenario:
1. User klik kursi 3 → kursi 3 jadi terpilih (hitam)
2. User klik kursi 6 → tidak ada respons, kursi 6 tidak bisa dipilih
3. Tapi jika user pilih dari dropdown di form penumpang, bisa ganti

**Root Cause:**
Fungsi `selectSeat(seat)` di Alpine.js hanya mencari penumpang yang belum punya kursi (`!passenger.seat_number`). Jika semua penumpang sudah punya kursi, fungsi return tanpa melakukan apa-apa.

**Yang Harus Diperbaiki:**
1. Modifikasi fungsi `selectSeat(seat)` agar:
   - Jika user klik kursi yang sudah dipilih → deselect (hapus dari penumpang tersebut)
   - Jika user klik kursi baru dan ada penumpang tanpa kursi → assign ke penumpang tersebut
   - Jika user klik kursi baru dan SEMUA penumpang sudah punya kursi → ganti kursi penumpang terakhir (atau tampilkan konfirmasi)

2. Tambahkan fungsi `deselectSeat(seat)` yang menghapus kursi dari penumpang yang memilikinya

3. Pastikan fungsi `isSelected(seat)` dan `isBooked(seat)` bekerja dengan benar

4. Test scenario:
   - Pilih kursi 3 → kursi 3 hitam
   - Pilih kursi 6 → kursi 6 hitam, kursi 3 putih (karena diganti)
   - Klik kursi 6 lagi → kursi 6 putih (deselect)
   - Pilih kursi 3 lagi → kursi 3 hitam

// 1. Pendapatan 6 bulan terakhir
$revenueByMonth = Payment::where('status', 'verified')
    ->where('paid_at', '>=', now()->subMonths(6))
    ->selectRaw('DATE_FORMAT(paid_at, "%Y-%m") as month, SUM(amount) as total')
    ->groupBy('month')
    ->orderBy('month')
    ->get();

// 2. Okupansi per rute (top 5)
$routeOccupancy = TravelRoute::with(['bus', 'orders' => function($q) {
        $q->whereIn('order_status', ['paid', 'completed']);
    }])
    ->where('status', 'available')
    ->get()
    ->map(function($route) {
        $totalPassengers = $route->orders->sum('total_passengers');
        $totalSeats = $route->bus->total_seats;
        $occupancy = $totalSeats > 0 ? ($totalPassengers / $totalSeats) * 100 : 0;
        return [
            'route' => $route->origin_city . ' → ' . $route->destination_city,
            'occupancy' => round($occupancy, 2)
        ];
    })
    ->sortByDesc('occupancy')
    ->take(5)
    ->values();

// 3. Order per status
$ordersByStatus = Order::selectRaw('order_status, COUNT(*) as total')
    ->groupBy('order_status')
    ->get();

// 4. Trend order 7 hari terakhir
$ordersTrend = Order::where('created_at', '>=', now()->subDays(7))
    ->selectRaw('DATE(created_at) as date, COUNT(*) as total')
    ->groupBy('date')
    ->orderBy('date')
    ->get();

// 5. Statistik per bus
$busStats = Bus::with(['routes.orders' => function($q) {
        $q->whereIn('order_status', ['paid', 'completed']);

        $totalPassengers = $bus->routes->flatMap->orders->sum('total_passengers');
        $totalSeats = $bus->total_seats * $bus->routes->count(); // Asumsi
        $occupancy = $totalSeats > 0 ? ($totalPassengers / $totalSeats) * 100 : 0;
        return [
            'bus_name' => $bus->bus_name,
            'total_passengers' => $totalPassengers,
            'occupancy' => round($occupancy, 2)
        ];
