# PO CAN TRAVEL — UI REDESIGN TAHAP 2

## Product-Level Redesign, Bukan Sekadar Restyling

Redesign tahap pertama sudah diterapkan dan business logic tetap aman.

Validasi terakhir:

```text
php artisan view:cache       PASS
npm run build                PASS
php artisan test             PASS
66 tests
233 assertions
```

Namun hasil visual masih terlalu polos dan generik.

Masalah utama:

> UI sekarang terasa seperti template dashboard yang diberi warna baru, bukan aplikasi booking tiket bus yang benar-benar dirancang untuk pengguna.

Saya ingin Anda melakukan **REDESIGN UI TAHAP 2 secara menyeluruh**.

Jangan hanya mengganti warna, border-radius, shadow, atau spacing.

Saya ingin perubahan pada:

* visual hierarchy
* information architecture
* komposisi halaman
* travel context
* bus information
* trip status
* booking experience
* order experience
* ticket experience
* responsive UX
* visual identity

# HASIL YANG SAYA INGINKAN

Jangan berhenti pada:

> "UI sudah modern dan responsive."

Saya ingin perubahan yang terlihat jelas ketika halaman dibuka.

Pengguna harus langsung memahami:

```text
Saya sedang di mana?
Saya mau pergi ke mana?
Kapan saya berangkat?
Bus apa yang saya gunakan?
Berapa kursinya?
Berapa harganya?
Apa status pesanan saya?
Apa yang harus saya lakukan berikutnya?
```

Desain harus menjawab pertanyaan tersebut secara visual.

**Prioritas utama:**

```text
Travel context
+
Information hierarchy
+
Booking UX
+
Visual identity
+
Responsive UX
```

bukan sekadar:

```text
rounded cards
+
shadow
+
gradient
+
icons
```

Mulai dari **PHASE A saja**.

Sebelum coding, baca file existing dan jelaskan secara singkat:

1. masalah UI saat ini
2. struktur UI baru
3. komponen yang akan digunakan
4. informasi travel baru yang dapat ditampilkan dari data existing

Setelah itu implementasikan PHASE A.
